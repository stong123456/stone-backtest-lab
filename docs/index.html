Four-layer Architecture

从数据接入到因子标准化，再到信号评分和执行反馈，所有模块都为可解释、可回测、可接入 Agent 服务。

01

Data Ingestion

接入 CEX、DEX、链上、预测市场、社交情绪和事件数据，形成统一输入层。

02

Factor Normalization

把不同量纲的数据清洗、去重，并归一化为可比较的因子分。

03

Signal Scoring

通过权重、环境过滤和风险惩罚，输出方向、强度、质量和过期时间。

04

Execution Feedback

把回测、模拟和执行结果回流到因子库，持续修正信号质量。
