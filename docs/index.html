BACKTEST FIRST · TRADE LATER

先回测，再谈交易。

这是一个面向加密货币策略研究的本地回测工具。它不需要 API Key，不替你下单，只负责把交易想法丢进真实历史 K 线里跑一遍，看看胜率、收益、回撤、交易频率和成本以后还站不站得住。

查看开源仓库 查看 Bitget 90 天报告 
python -m pip install -r requirements.txt
python scripts/hermes_backtest_lab.py --preset demo

python scripts/hermes_backtest_lab.py \
  --data-source bitget \
  --symbols BTC,ETH,SOL,SUI \
  --inst-type SWAP \
  --days 90 \
  --bar 1H
Data

多数据源

支持 OKX、Bitget、GeckoTerminal。可以跑现货、USDT 永续、链上 Token，并支持自定义历史区间。

Strategy

策略质检

内置趋势、均值回归、ATR、ADX、RSI、EMA、布林、成交量 z-score 等常用因子，方便快速验证想法。

Report

可视化报告

自动生成 HTML 报告，包含收益曲线、回撤、K 线与交易标记、逐笔交易明细、metrics.json 和 trades.csv。

它解决什么问题

避免凭感觉交易：任何策略先过历史数据和成本这一关。
看清亏损结构：不只看胜率，也看最大回撤、连续亏损、盈亏比和交易分布。
减少纸面收益：手续费、滑点、杠杆、保证金、仓位上限都能纳入模拟。
方便开源复现：本地运行、无密钥依赖、输出文件清晰，适合分享和二次开发。
